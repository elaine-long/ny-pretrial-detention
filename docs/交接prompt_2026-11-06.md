## 新项目要点

- **研究问题**：在纽约，提审时的羁押决定在多大程度上由案件和前科解释？剩下的差异来自县、法官还是被告的种族？这些差异和被释放者实际的到庭风险一致吗？
- **数据**：NY OCA Pretrial Release Data，公开 CSV，一行一个提审案件，131 列。已下载 2021（246,202 行）、2022（286,588）、2023（324,619）到 `data/raw/`；网站还有 2020、2024、2025。关键字段：释放决定（五类）、指控等级与暴力重罪标记、三类前科数、待决案件、监管状态、种族族裔性别年龄、县法院法官、保释金额、审前逮捕令、再逮捕。
- **三个子问题**：Q1 预测是否设保释或收押（`y_detain`）；Q2 三组嵌套特征（案件与前科 → 加县/法院/辩护人类型 → 加法官）的增量 + SHAP + 按种族的校准与误差 + 县/法官残差；Q3 在被释放者中预测未到庭（`y_warrant`），和 Q1 的决定交叉。补充一页：设保释者约 75% 从未交上。
- **划分**：2021–2022 训练，2023 验证，测试年待定（2024 或 2023 后半）。
- **2022 年初步数字**（未控制变量）：去掉当庭结案 20% 后 228,388 案；设保释或收押全州 21.6%、纽约市 18.9%；纽约市重罪按种族黑人 41.8% / 白人 34.9% / 亚裔 29.4%；重罪按县 Nassau 23.9% 到 Monroe 59.7%；纽约市 82 位法官 P10–P90 为 25.8%–54.4%；案件 + 前科 logistic AUC 0.87。被释放者未到庭 14.5%，黑人 14.8% / 白人 15.1%，AUC 0.76。前科缺失 13%，种族未知 16.5%。
- **法律背景**（引用前核实）：纽约 2020 年保释改革，法官依法只能考虑到庭风险，不能考虑再犯风险；2020/7、2022、2023 有修正。所以主结果不用"再逮捕"。
- **不做的**：不评价保释改革好坏；不给法官实名排名（用匿名 `judge_id`）；不做因果推断。
