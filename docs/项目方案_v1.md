## 0. 一句话

> 在纽约，提审时的羁押决定在多大程度上由案件和前科解释？剩下的差异来自县、法官还是被告的种族？这些差异和被释放者实际的到庭风险一致吗？

英文（slides）：
> How much of New York's pretrial detention decisions is explained by the case and the defendant's record, how much by where and before whom the case is arraigned and by the defendant's race, and do these differences track the actual risk of failing to appear?

---

## 1. 定义问题（Frame the problem）

### 1.1 政策背景

- **审前羁押不是刑罚。** 被羁押的人尚未定罪。几天羁押就可能丢工作、丢住房、无人照看子女；研究发现审前羁押提高认罪概率和定罪率（Dobbie, Goldin & Yang 2018, *AER* **[核实]**）。
- **纽约 2020 年保释改革**：多数轻罪和非暴力重罪不得设金钱保释，法官只能考虑**到庭风险**（flight risk），不能考虑再犯风险；2020 年 7 月、2022 年、2023 年各有修正，扩大了可设保释的罪名范围 **[核实具体条款]**。改革是全国争议焦点。
- **已知的学术发现**：Arnold, Dobbie & Yang (2018, *QJE*) 用纽约和迈阿密数据发现保释法官对黑人被告存在歧视 **[核实]**；Kleinberg et al. (2018, *QJE*) 用纽约市数据证明机器学习预测的到庭风险能在不增加犯罪的情况下减少羁押 **[核实]**。

### 1.2 决策、决策者、时点

| 决策 | 谁 | 什么时候 | 当时能看到什么 |
|---|---|---|---|
| 释放 / 非金钱条件释放 / 设保释 / 收押 | 提审法官 | 被捕后 24 小时左右的提审 | 指控、前科、待决案件、监管状态、被告基本信息、辩护人类型 |
| 到庭支持服务（提醒、交通、监督）投向谁 | 审前服务机构（纽约市 CJA 等） | 释放之后 | 同上 |

模型用的信息全部是提审当下已有的，所以老师在住房项目里的"机构能否观察到"问题在这里不存在。

### 1.3 三个子问题

| # | 子问题 | 对应方法 | 政策含义 |
|---|---|---|---|
| **Q1** | 羁押决定能被案件和前科预测到什么程度？ | 五个分类模型，Y = 是否设保释或收押 | 决定有多"规则化" |
| **Q2** | 剩下的差异来自县、法官还是种族？ | 模型比较（加/不加地点）、SHAP、按种族的分组误差 | 一致性与公平性；是否需要统一标准 |
| **Q3** | 决定和实际的到庭风险一致吗？ | 在被释放者中预测未到庭；把预测风险和 Q1 的决定交叉 | 羁押是否投向了高风险者；到庭支持该投向谁 |

补充一页：设了保释的人有多少交不上（金钱保释的实际效果 = 羁押）。

### 1.4 初步数字（2022，去掉提审当庭结案的 20%）

| 指标 | 数字 |
|---|---|
| 案件数 | 228,388（纽约市 123,089） |
| 设保释或收押 | 全州 21.6%，纽约市 18.9%，市外 24.7% |
| 纽约市重罪，按种族（原始） | 黑人 41.8%，白人 34.9%，亚裔 29.4% |
| 纽约市重罪，非暴力无前科 → 暴力 + 2 次暴力前科 | 21.6% → 68.1% |
| 重罪，按县 | Nassau 23.9% … Kings 44.0% … Monroe 59.7% |
| 纽约市重罪，82 位法官（≥200 案）P10 / P50 / P90 | 25.8% / 39.3% / 54.4% |
| 只用案件 + 前科的 logistic AUC | 0.87 |
| 设保释者提审当天交上 / 整个审前期间从未交上 | 11.3% / 约 75%；纽约市重罪现金保释中位数 $10,000 |
| 纽约市被释放者未到庭（签发逮捕令） | 14.5%；黑人 14.8%，白人 15.1% |
| 未到庭按轻罪前科 0 / 1 / 2 / 3+ | 9.9% / 14.5% / 18.5% / 29.6% |
| 未到庭 logistic AUC | 0.76 |

苗头：羁押决定按种族差 7 个点，到庭结果按种族几乎不差。这正是 Q2 和 Q3 要正式检验的。

## 2. 获取与探索数据（Get and explore）

### 2.1 数据

- **来源**：纽约州统一法院系统（OCA）Pretrial Release Data，公开 CSV，每个提审年一个文件，2020–2025。[下载页](https://www.nycourts.gov/division-technology-court-research/pretrial-release-data)
- **单位**：一行一个提审案件（`Internal_Case_ID`；`arr_cycle_id` 标识同一逮捕周期）。
- **规模**：2021 年 246,202 行，2022 年 286,588 行，2023 年 324,619 行；131 列。
- **字段组**：案件（最重指控、等级 A–E 级重罪 / A–B 级轻罪、暴力重罪标记、罪名类别、仇恨犯罪）；被告（种族、族裔、性别、年龄）；法院（县、法院、法院类型、**法官姓名**、地区）；前科（暴力重罪 / 非暴力重罪 / 轻罪定罪数，待决案件，是否在缓刑假释中，来自 DCJS 匹配）；决定（五类释放决定、非金钱条件、保释金额和形式、检方请求）；结果（审前逮捕令、再逮捕及等级、180 天再逮捕、羁押天数、处置）。
- **文档**：数据字典（xlsx）、数据说明（PDF）、处置层级（PDF），已下载到 `1106 方案修订/ny_data/`。

### 2.2 样本定义 **[定]**

1. 提审年 2021–2023（2020 年有改革首年 + 疫情，不用；2024 可作额外测试 **[定]**）。
2. 去掉提审当庭结案的案件（约 20%，没有羁押决定）。
3. **主分析：纽约市五县**（法院体系统一，约 12–15 万案件 / 年）；全州作对比分析。
4. 去掉释放决定为 Unknown 的案件（约 3%）。
5. Q3 的样本：Q1 样本中**被释放的**（无条件释放、非金钱条件释放、设保释且交上）。

每一步记录行数，做样本流程表。

### 2.3 探索要回答的

- 羁押率按年、县、等级、罪名类别、种族、年龄、辩护人类型。
- 前科分布与缺失（13% 缺失，来自 DCJS 匹配失败，要看是否与县或年份相关）。
- 种族 Unknown 16.5%，是否集中在某些县或法院。
- 法官案件量分布；县 × 法院类型。
- 未到庭率和再逮捕率按同样的维度。
- **要有一个发现**（回应老师对上一轮 EDA 的批评）：候选是"县之间的羁押率差异（24%–60%）远大于案件结构能解释的部分"或"同样的案件和前科，纽约市内法官之间差 30 个百分点"。

## 3. 准备特征（Prepare features）

### 3.1 三组特征 **[定]**

| 组 | 内容 | 用途 |
|---|---|---|
| **C 案件与前科** | 指控等级、暴力重罪标记、罪名类别、未遂标记、仇恨犯罪；三类前科数、三类待决、监管状态；逮捕类型（拘捕 / 传票）；年龄、性别 | 主模型：决定"应当"依据的信息 |
| **C + 地点** | C + 县（或法院）、法院类型、辩护人类型 | 回答"地点解释多少" |
| **C + 地点 + 法官** | 再加法官（匿名编号） | 回答"法官解释多少"；法官作高维类别处理 |

**种族、族裔只用于公平性分析，永远不进模型。**

### 3.2 泄露规则

决定之后才产生的字段一律不进特征：非金钱条件、保释金额与形式、检方请求、逮捕令、再逮捕、羁押天数、处置、判决。Q3 预测未到庭时，释放类型本身（无条件 vs 非金钱条件 vs 交保）是决定的结果，不进特征（可作分组）。

### 3.3 预处理

类别 one-hot（法官用频数截断 + 其他）；前科缺失单独标记；年龄分组或连续；全部在训练折内拟合。

## 4. 选择与调参模型（Select and tune）

### 4.1 划分 **[定]**

| 用途 | 年份 |
|---|---|
| 训练 | 2021、2022 |
| 验证（选模型、调参、定阈值） | 2023 |
| 测试（只跑一次） | 2024（若下载）或 2023 后半年 **[定]** |

按年份切分的理由：规则逐年修正，要检验前一年学到的规律在后一年是否成立。

### 4.2 模型

| 模型 | 作用 | 负责 |
|---|---|---|
| Logistic（L2） | 可解释基线 | D |
| LASSO Logistic（L1） | 哪些特征真的有用 | D |
| Decision Tree | 可读的决策规则 | D |
| Random Forest | 交互 | E |
| XGBoost | 最强预测 | E |

嵌套交叉验证调参；指标用 PR-AUC 或 AUC **[定]**。

### 4.3 基准

- 只用指控等级的规则（例如暴力重罪 → 羁押）。
- 多数类（只用于准确率和 Brier）。

## 5. 评估（Evaluate）

### 5.1 Q1：可预测性

AUC、PR-AUC、校准；三组特征的比较：从 C 到 C + 地点到 C + 法官，AUC 各增加多少 = 地点和法官的"解释力"。

### 5.2 Q2：差异来源与公平性

- SHAP：最优模型里哪些变量主导。
- 按种族的分组指标：同样的预测概率下，实际羁押率是否不同（校准差异）；固定阈值下的 FPR / FNR。
- 县和法官的"残差"：实际羁押率减模型预测率，按县和法官汇总，画图（法官匿名）。

### 5.3 Q3：决定与风险是否一致

- 在被释放者中训练未到庭模型，报告 AUC 和分组指标。
- 把 Q3 的预测风险按分位数分组，看每组的实际羁押率（Q1）：羁押是否集中在高风险者。
- 按种族比较：羁押率差距 vs 到庭风险差距。
- 局限：被羁押者的到庭风险观察不到（selective labels），只能说"在被释放的人中"。

### 5.4 聚类

在 C 组特征上对案件聚类（不含决定和结果），得到几类典型案件；报告每类的羁押率、县间差异和未到庭率。回答"哪类案件的裁量空间最大"。

### 6.2 政策含义怎么写

- 如果县 / 法官解释了大量差异：建议法院系统发布参考标准、给法官看自己的分布。
- 如果种族差距在控制后仍在且不对应风险差距：这是公平性问题，建议审计机制。
- Q3 的高风险被释放者：到庭支持服务（提醒、交通）的投向。
- 保释交不上的 75%：金钱保释在实际中等于羁押。

**不做的**：不评价保释改革好坏；不预测"再犯"作为主结果；不给法官实名排名。

## 7. 局限

- 被羁押者的到庭风险不可观测；Q3 只对被释放者成立。
- 前科缺失 13%、种族未知 16.5%，要检查缺失机制。
- 法官分配不是随机的（按法院轮值），法官差异可能部分反映案件分配。
- 规则逐年变化；跨年验证同时检验了规则变化。
- 没有辩护质量、证据强度、被告就业等信息。
- 数据是行政记录，不是抽样调查，没有权重问题。
